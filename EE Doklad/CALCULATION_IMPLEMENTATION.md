# Имплементация на изчисления за студен покрив (Ur)

## Преглед
Имплементирани са всички необходими изчисления за коефициента на топлопреминаване на студен покрив (Ur) според предоставените формули.

## Формули

### 1. Rse1 = Rsi2 (Съпротивление при топлоотдаване)
```
Rse1 = Rsi2 = δвс / (2 * λекв)
```
- δвс — дебелина на въздушния слой (m)
- λекв — еквивалентна топлопроводност (W/mK)

### 2. U1 (Таванска плоча)
```
U1 = 1 / (0.10 + Σ(δj/λj) + Rse1)
```

### 3. U2 (Покривна плоча)
```
U2 = 1 / (Rsi2 + Σ(δj/λj) + 0.04)
```

### 4. Uw (Вертикални ограждения)
```
Uw = 1 / (Σ(δj/λj) + 0.13 + 0.04)
```

### 5. Ur (Общ коефициент)
```
Ur = 1 / (1/U1 + A1/(A2*U2 + Aw*Uw + 0.33*n*V))
```

## Имплементирани методи в ColdRoofDetail

### CalculateRse1Rsi2()
Изчислява съпротивлението при топлоотдаване в подкровното пространство.

### CalculateU1()
Изчислява коефициента на топлопреминаване на таванската плоча.

### CalculateU2()
Изчислява коефициента на топлопреминаване на покривната плоча.

### CalculateUw()
Изчислява коефициента на топлопреминаване на вертикалните ограждения.

### CalculateUr()
Изчислява крайния коефициент на топлопреминаване на студения покрив.

## Автоматично обновяване

Всички изчислени стойности се обновяват автоматично при промяна на:
- Геометрия (Vp, Ap, Deltavc)
- Площи (A1, A2, Aw)
- Вентилация (n, V)
- Температури (Ti, Te)
- Слоеве на конструкциите (U1, U2, Uw)

## Визуализация

В UI се показват:
- **Rse1 = Rsi2** — съпротивление при топлоотдаване (m²K/W)
- **U1 (изчислен)** — коефициент за таванска плоча (W/m²K)
- **U2 (изчислен)** — коефициент за покривна плоча (W/m²K)
- **Uw (изчислен)** — коефициент за вертикални ограждения (W/m²K)
- **Ur** — краен коефициент за студен покрив (W/m²K)

## Използване

1. Въведете всички необходими данни за геометрия, площи, вентилация и температури
2. Добавете слоевете за U1, U2 и Uw конструкциите
3. Натиснете бутона "Изчисли"
4. Резултатът Ur ще се появи заедно с междинните стойности

## Валидация

Изчислението се извършва само ако:
- Всички стойности U1, U2, Uw са > 0
- Всички площи A1, A2, Aw са > 0
- Има валидни данни за λекв и δвс

Ако някое от условията не е изпълнено, Ur се показва като "—".
