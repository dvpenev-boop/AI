## Основни формули (имплементирани)

### 1. U-стойности по ISO 6946
```
U = 1 / (Rsi + Σ(δᵢ/λᵢ) + Rse)
```

### 2. Контакт със земята
```
df = d_we + λg · R_fb
B = A / (0.5 · P)

Ако df + 0.5·z < B:
  Uf_gb = (2·λg) / (π·(B + df + 0.5·z)) · ln((π·B)/(df + 0.5·z) + 1)
Иначе:
  Uf_gb = λg / (0.457·B + df + 0.5·z)

d_wb = λg · R_wb
Uw_gb = (2·λg) / (π·z) · (1 + 0.5·df'/(df' + z)) · ln(z/d_wb + 1)
```

### 3. Вентилация
```
Hve_b = cp · ρ · n · V
```

### 4. Еквивалентен коефициент
```
S = (A·Uf_gb) + (z·P·Uw_gb) + (h·P·Uw) + Hve_b
Uub = 1 / ((1/Uf_sus) + (A/S))
```
