# Changelog - версия 1.1

## Поправки и подобрения (13 януари 2026)

### 🐛 Поправен бъг с ListBox
**Проблем:** При добавяне на нова секция тя не се показваше в списъка вляво (въпреки че работеше в PDF експорта).

**Решение:** Заменена `List<Section>` с `ObservableCollection<Section>` в `Report.cs`. Сега промените в списъка със секции се отразяват автоматично в GUI без допълнителен код.

**Засегнат файл:**
- `Models/Report.cs` - `List<Section>` → `ObservableCollection<Section>`
