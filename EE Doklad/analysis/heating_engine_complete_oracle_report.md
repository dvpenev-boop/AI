# Complete EECalc-compatible monthly heating oracle

## Summary

Implemented test-only standalone oracle:

`EE.Doklad.Tests/Validation/EecalcMonthlyHeatingOracle.cs`

The oracle combines the validated/reverse-engineered EECalc blocks:

- R1 `MonthlyDays`
- climate monthly `AvgTemp` and solar radiation inputs
- R2 `Hve` / `Qve`
- R3 `Hd`, `Hg`, `Hu`, `Htr`, `Qtr`
- R4 `Qgn` solar-only gains
- R5 `Gamma`, `aH`, `Ni`, `Qnd`

No production code or UI code was modified.

## Implemented pipeline

For each heating month:

```text
MonthlyDays = EecalcMonthlyDaysOracle.Calculate(fixture.Calculation)
AvgTemp = fixture.AverageOutdoorTemperatureByMonth[month]
Hve = HeatedVolume * Infiltration * 0.34
AvgInnerHeatTemp = weighted project/non-project indoor temperature
Htr = Hd + Hg + Hu
DegreeHours = project/non-project degree-hour logic
Qtr = Htr * DegreeHours / 1000
Qve = Hve * DegreeHours / 1000
Qht = Qtr + Qve
QgnRaw = (TransparentFsol + NonTransparentFsol) * TotalHours
Qgn = QgnRaw / 1000
MetabolicHeatPerArea = MetabolicHeat * OccupantHours / 1000
MetabolicHeat = MetabolicHeatPerArea * HeatedArea
Gamma = (Qgn + MetabolicHeat) / Qht
tau = HeatedArea * HeatCapacity / (Htr + Hve)
aH = 1 + tau / 15
Ni = EECalc piecewise gamma formula
RawQnd = Qht - Ni * Qgn
FinalQnd = RawQnd / HeatedArea - Ni * MetabolicHeatPerArea
```

## Preserved known differences

- KD-004: `SumWallDirecrionsHu1` preserves `NorthWalls * 8` through existing R3 oracle.
- `A5 * A5` quirks are preserved in existing R3 wall/ceiling Hu methods.
- Baseline current-envelope behavior is documented and the oracle structure keeps mode-specific formulas separate for future baseline support.
- `Qgn` is solar only; occupants/lights/devices are not added into `Qgn`.
- Ref1/Ref2 use baseline Qgn: documented for future extension, not compared in this actual-mode oracle.
- Gamma tolerance bug is preserved: strict `< 0.01` and `> 0.01`; `gamma == 0.99` and `gamma == 1.01` fall through to `0.0`.
- Double Qnd assignment is represented by both `RawQnd` and `FinalQnd`.
