# Тестови примери за изчисление на Ur

## Пример 1: Основен тест

### Входни данни:
- **Геометрия:**
  - Vp = 100 m³
  - Ap = 50 m²
  - δвс = 2.0 m

- **Площи:**
  - A1 = 50 m²
  - A2 = 55 m²
  - Aw = 20 m²

- **Вентилация:**
  - Тип: уплътнено
  - n = 0.1 h⁻¹
  - V = 100 m³

- **Температури:**
  - Ti = 20°C
  - Te = 4°C

- **Конструкции:**
  - **U1 (таванска плоча):**
    - Слой 1: δ=0.15m, λ=1.4 W/mK → R=0.107
  
  - **U2 (покривна плоча):**
    - Слой 1: δ=0.20m, λ=1.6 W/mK → R=0.125
  
  - **Uw (вертикални ограждения):**
    - Слой 1: δ=0.25m, λ=0.8 W/mK → R=0.313

### Очаквани стъпки на изчисление:

1. **Изчисление на ThetaU** (температура в подкровното пространство)
2. **Изчисление на ThetaSe1, ThetaSi2**
3. **Изчисление на λекв** (еквивалентна топлопроводност)
4. **Изчисление на Rse1 = Rsi2:**
   ```
   Rse1 = Rsi2 = δвс / (2 * λекв)
   ```

5. **Изчисление на U1:**
   ```
   U1 = 1 / (0.10 + Σ(δj/λj) + Rse1)
   U1 = 1 / (0.10 + 0.107 + Rse1)
   ```

6. **Изчисление на U2:**
   ```
   U2 = 1 / (Rsi2 + Σ(δj/λj) + 0.04)
   U2 = 1 / (Rsi2 + 0.125 + 0.04)
   ```

7. **Изчисление на Uw:**
   ```
   Uw = 1 / (Σ(δj/λj) + 0.13 + 0.04)
   Uw = 1 / (0.313 + 0.13 + 0.04)
   Uw = 1 / 0.483
   Uw ≈ 2.070 W/m²K
   ```

8. **Изчисление на Ur:**
   ```
   Ur = 1 / (1/U1 + A1/(A2*U2 + Aw*Uw + 0.33*n*V))
   ```

### Как да тествате в приложението:

1. Отворете секция 7 "Покрив"
2. Добавете студен покрив (тип 1)
3. Въведете горните данни
4. Натиснете "Изчисли"
5. Проверете резултатите в секцията "Изчислени коефициенти"

### Проверка на резултатите:

- ✓ Всички междинни стойности (Rse1, U1, U2, Uw) трябва да са положителни числа
- ✓ Ur трябва да е положително число
- ✓ Типични стойности за Ur са между 0.1 и 2.0 W/m²K

## Пример 2: Граничен случай

### Входни данни с минимални стойности:
- Vp = 10 m³
- Ap = 10 m²
- A1 = 10 m²
- A2 = 10 m²
- Aw = 5 m²
- Ti = 20°C
- Te = 0°C

### Очакван резултат:
- Изчислението трябва да работи без грешки
- Всички стойности трябва да са валидни

## Забележки:

- Ако някоя стойност е 0 или отрицателна, Ur ще бъде показано като "—"
- Ако λекв не може да се изчисли (поради липса на данни за ThetaU), всички изчисления ще бъдат невалидни
- Уверете се, че всички слоеве имат положителни стойности за δ и λ
