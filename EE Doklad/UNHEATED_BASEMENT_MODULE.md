# Модул: Под към неотопляем сутерен – еквивалентен коефициент Uub

## Преглед

Този модул изчислява еквивалентния коефициент на топлопреминаване **Uub** за под между отопляемо помещение и неотопляем сутерен, като включва изчисление на контакта със земята.

## Входни параметри

### Геометрия
| Параметър | Обозначение | Единица | Описание |
|-----------|-------------|---------|----------|
| Area | A | m² | Площ на пода между отопляемото и сутерена |
| Perimeter | P | m | Периметър на сутерена |
| DepthBelowGround | z | m | Дълбочина на сутеренните стени под терена |
| HeightAboveGround | h | m | Височина на сутеренните стени над терена |
| Volume | V | m³ | Обем на неотопляемия сутерен |

### Параметри за земята
| Параметър | Обозначение | Стойност по подразбиране | Единица |
|-----------|-------------|-------------------------|---------|
| LambdaGround | λg | 2.0 | W/m·K |

### Вентилация
| Параметър | Обозначение | Стойност по подразбиране | Единица |
|-----------|-------------|-------------------------|---------|
| AirChangeRate | n | 0.3 | 1/h |
| AirDensity | ρ | 1.2 | kg/m³ |
| AirSpecificHeat | cp | 0.28 | Wh/(kg·K) |

### Топлинни съпротивления
| Елемент | Rsi | Rse |
|---------|-----|-----|
| Под отопляемо → сутерен | 0.17 | 0.17 |
| Подова плоча на сутерена | 0.17 | 0.00 |
| Стени на сутерена към земя | 0.13 | 0.00 |
| Стени на сутерена над терена | 0.13 | 0.04 |

### Конструкции (слоеве)
Всеки елемент се описва с многослойна конструкция:
- **FloorToBasementLayers** - Под между отопляемото и сутерена
- **BasementFloorLayers** - Подова плоча на сутерена към земя
- **BasementWallLayers** - Стени на сутерена към земя
- **WallAboveGradeLayers** - Стени на сутерена над терена

## Изчислителен алгоритъм

### Стъпка 1: U-стойности по ISO 6946

#### 1.1 Под между отопляемото и сутерена (Uf_sus)
```
R_layers = Σ(δᵢ / λᵢ)
R_total = Rsi + R_layers + Rse
Uf_sus = 1 / R_total
```

#### 1.2 Подова плоча на сутерена (R_fb)
```
R_layers = Σ(δᵢ / λᵢ)
R_fb = Rsi + R_layers + Rse
```

#### 1.3 Сутеренни стени към земя (R_wb)
```
R_layers = Σ(δᵢ / λᵢ)
R_wb = Rsi + R_layers + Rse
```

#### 1.4 Сутеренни стени над терена (Uw)
```
R_layers = Σ(δᵢ / λᵢ)
R_total = Rsi + R_layers + Rse
Uw = 1 / R_total
```

### Стъпка 2: Контакт със земята

#### 2.1 Еквивалентна дебелина на подовата плоча
```
df = d_we + λg · R_fb
```

#### 2.2 Характеристичен размер
```
B = A / (0.5 · P)
```

#### 2.3 Коефициент на пода на сутерена към земя (Uf_gb)

**Ако df + 0.5·z < B:**
```
Uf_gb = (2·λg) / (π·(B + df + 0.5·z)) · ln((π·B)/(df + 0.5·z) + 1)
```

**Ако df + 0.5·z ≥ B:**
```
Uf_gb = λg / (0.457·B + df + 0.5·z)
```

#### 2.4 Еквивалентна дебелина на стените
```
d_wb = λg · R_wb
```

#### 2.5 Коефициент на стените на сутерена към земя (Uw_gb)
```
factor = 1 + (0.5·df') / (df' + z)
Uw_gb = (2·λg) / (π·z) · factor · ln(z/d_wb + 1)

Забележка: df' = min(df, d_wb)
```

### Стъпка 3: Вентилационна проводимост
```
Hve_b = cp · ρ · n · V
```

### Стъпка 4: Еквивалентен коефициент Uub

#### 4.1 Сборен "изход" от сутерена
```
S = (A · Uf_gb) + (z · P · Uw_gb) + (h · P · Uw) + Hve_b
```

#### 4.2 Краен резултат
```
Uub = 1 / ((1/Uf_sus) + (A/S))
```

## Изходни резултати

### Основен изход
- **Uub** (W/m²K) - Еквивалентен коефициент на топлопреминаване

### Диагностични изходи
| Променлива | Описание | Единица |
|------------|----------|---------|
| Uf_sus | Под между отопляемото и сутерена | W/m²K |
| Uf_gb | Под на сутерена към земя | W/m²K |
| Uw_gb | Стени на сутерена към земя | W/m²K |
| Uw | Стени на сутерена над терена | W/m²K |
| Hve_b | Вентилационна проводимост | W/K |
| B | Характеристичен размер | m |
| df | Еквивалентна дебелина на подовата плоча | m |
| d_wb | Еквивалентна дебелина на стените | m |
| S | Сборен изход от сутерена | W/K |

## Проверки и ограничения

1. A > 0, P > 0 (задължително)
2. Всички геометрични параметри ≥ 0
3. Всички U > 0
4. Ако V = 0 → Hve_b = 0
5. Ако h = 0 → членът към въздуха отпада
6. Ако z = 0 → членът към земя през стени отпада
7. Ако d_wb < df → замени df = d_wb в формулата 2.5

## Пример за употреба

```csharp
var input = new FloorUnheatedBasementInput
{
    Area = 200.0,
    Perimeter = 60.0,
    DepthBelowGround = 2.0,
    HeightAboveGround = 0.3,
    Volume = 460.0,
    LambdaGround = 2.0,
    WallThicknessAtGrade = 0.3,
    AirChangeRate = 0.3
};

// Добавяне на слоеве...
input.FloorToBasementLayers.Add(new FloorLayer 
{ 
    Material = "Бетон", 
    Thickness = 0.2, 
    Lambda = 1.7 
});

var strategy = new UnheatedBasementFloorStrategy();
var result = strategy.Calculate(input);

Console.WriteLine($"Uub = {result.U:F4} W/m²K");
```

## Тригери за преизчисление

Модулът трябва да се преизчисли при промяна на:
- Геометрия (A, P, z, h, V)
- Слоеве (който и да е елемент)
- Кратност на въздухообмена (n)
- Топлопроводност на земята (λg) или дебелина на стените (d_we)

## Забележки

❗ **Важно:** Модулът:
- **НЕ** използва вътрешни/външни температури
- **НЕ** изчислява месечни загуби
- **НЕ** определя отоплителен сезон
- Само връща еквивалентния коефициент **Uub**

Месечните и сезонните изчисления се правят в следващ модул.
