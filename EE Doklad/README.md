# EE Доклад - Енергиен доклад

Windows настолно приложение за изготвяне на енергийни доклади по фиксиран шаблон.

## Възможности

✅ **Предефинирана структура с 20 секции**

✅ **Създаване на доклади с таблици**
- Всяка секция може да съдържа статичен текст и таблици
- Фиксирани таблици (с постоянен брой редове)

✅ **Ръчно въвеждане на данни**
- Дати
- Без формули (потребителят въвежда само стойности)

✅ **Запазване и зареждане на доклади**
- Формат: JSON
- Фиксиран формат (еднакъв на всяка машина)
- Автоматично отваряне след експорт
✅ **Офлайн работа**
- Не изисква интернет връзка

## Методика: климатични данни (read-only)

Приложението съдържа **вградени (embedded)** климатични данни по методиката, които:

- се **виждат** в UI от меню **„Данни → Климатични зони (методика)”**;
- са **само за преглед** (няма редакция през UI);
- се поддържат **само от инженер** чрез промяна на seed файла в сорс кода и нов билд.

### Къде е seed файлът

Файл: `EE.Doklad/Data/climate_zones.json` (в проекта е маркиран като `EmbeddedResource`).

### Метаданни в JSON

В root на JSON има следните полета:

- `ImportedBy` – **трябва да съдържа** текста за произхода от методиката (Приложение № 3):
  - `"Приложение № 3 към чл. 54, ал. 2, т. 1 от № РД-02-20-3 от 9.11.2022 г. изм. и доп. ДВ. бр.18 от 1 март 2024 г."`
- `Source` – например „БДС .../година”
- `Revision` – например `v1.0`
- `Date` – ISO дата (например `2026-01-25`)

### Как се обновяват данните (за инженери)

1) Редактирай `EE.Doklad/Data/climate_zones.json`.

2) Build приложението.

Данните се пакетират в билда/релийза и **не се очаква** да се променят от потребителя в runtime.

### Вариант 1: Стартиране от source code
```powershell
cd "E:\AI\EE Doklad\EE.Doklad"
dotnet run
```

### Вариант 2: Single-file executable (за разпространение)
```powershell
cd "E:\AI\EE Doklad\EE.Doklad"
dotnet publish -c Release -r win-x64 --self-contained true /p:PublishSingleFile=true /p:IncludeNativeLibrariesForSelfExtract=true
```

Изпълнимият файл ще бъде в: `bin\Release\net8.0-windows\win-x64\publish\EE.Doklad.exe`

## Използване

### 1. Създаване на нов доклад
- **Файл → Нов доклад** - създава празен шаблон с примерни данни
- Редактирайте заглавието на доклада

### 2. Добавяне на секции
- Натиснете **"+ Добави секция"** в левия панел
- Всяка секция има:
  - **Заглавие** - име на секцията (напр. "1. Обща информация")
  - **Статичен текст** - описание/въведение
  - **Таблици** - една или повече таблици с данни

### 3. Редактиране на данни
- Изберете секция от списъка вляво
- Попълнете/редактирайте полетата в дясно
- Данните се записват автоматично при промяна

### 4. Запазване на доклад
- **Файл → Запази...** - записва доклада като JSON файл
- Запазвайте често за да не загубите промени

### 5. Зареждане на доклад
- **Файл → Отвори...** - зарежда запазен JSON файл
- Ако имате незапазени промени, ще получите предупреждение

### 6. Експорт в PDF
- **Експорт → Експорт в PDF...** - генерира PDF файл
- PDF-ът се отваря автоматично след експорт
- Форматът е фиксиран и еднакъв на всяка машина

## Ограничения и забележки

⚠️ **Важно:**
- Приложението **не интерпретира нормативи** - само попълва данни
- **Не смята формули** - потребителят въвежда стойности ръчно
- Финалният PDF е **еднопосочен експорт** (не може да се редактира обратно)

⚠️ **QuestPDF лиценз:**
- Community license е **безплатен за некомерсиална употреба**
- За комерсиална употреба е необходим платен лиценз: [QuestPDF.com/license](https://www.questpdf.com/license)

## Поддръжка и разширяване

### Добавяне на нови таблици в секция
Редактирайте `MainViewModel.CreateSampleReport()` за да дефинирате нови таблици в шаблона.

### Промяна на PDF layout
Редактирайте `PdfGeneratorService.GeneratePdf()` за да настроите форматирането.

### Добавяне на нови типове клетки
Разширете `CellType` enum в `Models/Cell.cs` и добавете валидация в `Cell.IsValid()`.
